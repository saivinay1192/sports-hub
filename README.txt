SPORTS HUB - BASIC WEBSITE

Files:
1. index.html  - Main webpage
2. style.css   - Website styling and responsive design
3. script.js   - Basic JavaScript
4. README.txt  - Project information

HOW TO RUN:
1. Extract the ZIP file.
2. Open the sports_hub folder.
3. Double-click index.html.
4. The website will open in your browser.

You can edit index.html to add more sports and matches.
